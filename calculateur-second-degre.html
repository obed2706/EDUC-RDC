Calculateur d'équations du second degré

Résolvez ax² + bx + c = 0 et lisez chaque étape. Les calculs se font dans votre navigateur : rien n'est envoyé sur Internet. Vous pouvez écrire les décimaux avec une virgule ou un point.

Ce que le calculateur gère

  • Nombres négatifs et décimaux (le signe du discriminant est calculé de façon exacte).
  • Deux solutions, racine double, absence de solution réelle.
  • Le cas a = 0 : l'équation devient du premier degré, ou n'a pas de solution, ou est toujours vraie.
  • Valeurs invalides : un message précise le champ à corriger. Limite : 15 chiffres par coefficient.

Pour comprendre la méthode, lisez le discriminant expliqué simplement. Utilisez cet outil pour vérifier vos exercices, pas pour les remplacer.
