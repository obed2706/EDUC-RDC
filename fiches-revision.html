Premier degré

ax + b = 0 ⇒ x = −b/a (a ≠ 0)
  • Même opération des deux côtés.
  • Piège : −3x = 12 donne x = −4.
  • Toujours vérifier en remplaçant x.

Identités remarquables

(a + b)² = a² + 2ab + b²
(a − b)² = a² − 2ab + b²
(a + b)(a − b) = a² − b²
  • Piège : (a + b)² ≠ a² + b².
  • Produit nul : A × B = 0 ⇒ A = 0 ou B = 0.

Second degré

Δ = b² − 4ac
  • Δ > 0 : x = (−b ± √Δ)/(2a), deux solutions.
  • Δ = 0 : x = −b/(2a), une solution double.
  • Δ < 0 : aucune solution réelle.
  • Somme des racines : −b/a. Produit : c/a.
  • Piège : (−5)² = 25, et non −25.

Pythagore

c² = a² + b² (c : hypoténuse)
  • Valable uniquement dans un triangle rectangle.
  • N'oubliez pas la racine carrée finale.
  • Triplets utiles : 3-4-5, 5-12-13, 8-15-17, 7-24-25.

Pourcentages

  • p % de N : N × p/100.
  • Hausse de t % : × (1 + t/100). Baisse : × (1 − t/100).
  • Évolutions successives : on multiplie les coefficients.
  • Taux d'évolution : (finale − initiale) / initiale.
